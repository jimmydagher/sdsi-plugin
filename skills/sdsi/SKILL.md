# SDSI

This is the short entry for `sdsi:all`. Read `../all/SKILL.md` and follow it exactly, passing along any arguments given (`--review|--apply`, path or branch). To run a single topic instead, use `/sdsi:<topic>` (e.g. `/sdsi:security`).
